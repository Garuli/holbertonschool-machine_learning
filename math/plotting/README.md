# Plotting

Tasks from the Holberton School machine learning project on plotting
data with `matplotlib`: line graphs, scatter plots, bar graphs and
histograms.

| File | Description |
|------|-------------|
| `0-line.py` | Plots a cubic line graph |
| `1-scatter.py` | Scatter plot of men's height vs weight |
| `2-change_scale.py` | Line graph of C-14 decay with a log y-axis |
| `3-two.py` | Two line graphs: decay of C-14 and Ra-226 |
| `3-two.py` | Two line graphs: decay of C-14 and Ra-226 |
| `4-frequency.py` | Histogram of student grades for a project |
| `5-all_in_one.py` | All 5 previous graphs in one 3 x 2 figure |
| `6-bars.py` | Stacked bar graph of the fruit each person has |
| `100-gradient.py` | Scatter plot of mountain elevations with a colorbar |
| `101-pca.py` | 3D PCA visualization of the Iris dataset |
