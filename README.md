# Holberton School Machine Learning
My solutions for the Holberton School Machine Learning programme.

## Structure
- `math/`: mathematics foundations for machine learning
More topics will be added as the programme continues.

## Environment
- OS: Ubuntu 20.04 LTS / macOS
- Python 3.9
- numpy 1.25.2
- Style checker: pycodestyle 2.11.1

## Code conventions
- Every Python file starts with `#!/usr/bin/env python3`
- Every file is executable and ends with a new line
- Code follows `pycodestyle`
- Every module, class and function has a docstring
